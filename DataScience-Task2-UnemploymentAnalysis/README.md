# Unemployment Analysis with Python

## OASIS INFOBYTE Data Science Internship — Task 2

### Objective

Perform exploratory data analysis on unemployment data to understand regional and temporal unemployment trends in India, with a focus on the COVID-19 period.

### Work Completed

- Data loading and inspection
- Data cleaning and missing-value handling
- Descriptive statistics
- Region-wise unemployment analysis
- Month-wise unemployment trends
- Time-series analysis of major regions
- Top 10 regions with highest average unemployment
- Correlation heatmap
- Pre-COVID vs Post-COVID comparison
- Data visualizations and observations

### Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

### Conclusion

The analysis provides an understanding of regional and temporal unemployment patterns in India and highlights changes during the COVID-19 period.
