# Iris Flower Classification with Machine Learning

## OASIS INFOBYTE Data Science Internship — Task 1

### Objective
Classify Iris flowers into their respective species using machine learning.

### Work Completed
- Loaded and inspected the Iris dataset
- Checked missing values and data types
- Performed descriptive statistics
- Exploratory data analysis
- Visualized sepal and petal measurements
- Prepared training and testing data
- Logistic Regression
- K-Nearest Neighbors (KNN)
- Accuracy comparison
- Confusion matrices
- Classification reports
- Model comparison

### Best Model
K-Nearest Neighbors (KNN) achieved 100% accuracy on the test dataset and performed better than Logistic Regression in this experiment.

- Python
- Pandas
- NumPy

- Scikit-learn
