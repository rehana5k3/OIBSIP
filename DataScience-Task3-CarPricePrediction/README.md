# Car Price Prediction with Machine Learning

## OASIS INFOBYTE Data Science Internship — Task 3

### Objective
Build a machine learning model to predict the selling price of used cars.

### Work Completed
- Data cleaning and inspection
- Feature engineering
- Exploratory Data Analysis
- Car age calculation
- Brand extraction
- Categorical encoding
- Correlation analysis
- Train/test split
- Linear Regression
- Random Forest Regression
- Model evaluation using MAE, RMSE and R²
- Actual vs predicted price visualization
- Feature importance analysis
- Sample price prediction

### Best Model
Random Forest Regression performed better than Linear Regression on the test dataset.

### Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook
